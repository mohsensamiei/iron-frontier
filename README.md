# مرز آهنین (Iron Frontier)

بازی شهرسازی و استراتژی بی‌درنگ دوبعدی با نمای ایزومتریک، در یک فایل HTML. بدون نصب، روی مرورگر گوشی و کامپیوتر.

## حالت‌ها

- **تک‌نفره:** در برابر اردوگاه نارنجی با سه سطح دشواری. موج‌های حمله هر چند دقیقه می‌رسند.
- **دونفره رودررو:** تو در برابر دوستت.
- **دونفره همکاری:** دهکدهٔ مشترک در برابر دشمن هوش مصنوعی.

## بازی دونفره روی یک Wi-Fi

1. یک نفر صفحه را باز می‌کند و «ساخت بازی رودررو» یا «ساخت بازی همکاری» را می‌زند.
2. یک کد ۵ حرفی، QR و لینک نشان داده می‌شود.
3. نفر دوم QR را با دوربین گوشی می‌خواند، یا لینک را باز می‌کند، یا کد را در همین صفحه وارد می‌کند.

اتصال با WebRTC (کتابخانهٔ PeerJS) مستقیم بین دو مرورگر برقرار می‌شود. فقط برای پیدا کردن هم در لحظهٔ اتصال به اینترنت نیاز است. مرورگرِ سازندهٔ بازی کل بازی را اجرا می‌کند؛ اگر بسته شود بازی متوقف می‌شود.

## انتشار با GitHub Pages

Settings › Pages › Source: `Deploy from a branch` · Branch: `main` / `(root)` → Save.
بعد از یکی دو دقیقه بازی روی `https://<username>.github.io/iron-frontier/` در دسترس است.

## کنترل‌ها

| کار | موس و کیبورد | لمسی |
| --- | --- | --- |
| انتخاب | کلیک، یا کشیدن کادر | ضربه روی یگان خودی |
| فرمان (حرکت، حمله، برداشت، ساخت) | کلیک راست | ضربهٔ دوم روی هدف |
| جابه‌جایی دوربین | فلش‌ها یا لبهٔ صفحه | کشیدن با یک انگشت |
| زوم | چرخ موس، `+` و `-` | دو انگشت، دکمه‌های + و − |
| دیوار | کشیدن روی نقشه برای یک ردیف | کشیدن |
| تایید یا لغو ساخت | `Enter` / `Esc` | ✓ / ✗ |
| کماندار روی برج یا دیوار | کلیک راست روی برج یا دیوار | ضربه روی برج یا دیوار |
